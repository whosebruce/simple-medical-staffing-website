# Simple Medical Staffing Website

Public marketing website for Simple Medical Staffing.

This repository intentionally contains only public website code and public media. It does not contain the staffing operations platform, applicant records, credentials, production secrets, or private client data.

## Local verification

```bash
npm install
npm run verify
npm run start:static
```

The generated GitHub Pages site is written to `docs/` and includes the production `CNAME` file for `simplemedicalstaffing.com`.
