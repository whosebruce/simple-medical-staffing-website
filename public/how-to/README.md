# How-to videos for the app

Put the app's short how-to videos in this folder. The build publishes each one at
`https://simplemedicalstaffing.com/how-to/<name>.mp4`; this note is not published.

- Name: lowercase letters, digits and hyphens, ending in `.mp4` (for example `clock-in.mp4`).
- Keep each file small: a short screen recording should be a few MB. The build refuses anything over 50 MB.
- Everything here is public. Film on made-up data only: no real names, facilities, pay or patient details.

The full steps are in the repository README, under "How-to videos for the app".
